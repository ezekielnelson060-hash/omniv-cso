# OMNIV PRODUCT SPEC

## What is Omniv?

Omniv is a discovery network where people and organizations
publish things worth discovering and explorers discover them.

Core loop:

Publish → Discover → Follow/Save → Connect

## Omniv is NOT

- a traditional directory
- a generic social network
- a SaaS dashboard
- a blog platform
- only for companies
- only for artists
- only for articles

## Development rule

Build incrementally.

Never rewrite working systems unnecessarily.

Never add features not requested.

Prefer simple architecture.

Use reusable components.

Protect database access with Row Level Security.

Do not use fake production data.

Use mock data only during UI development.
