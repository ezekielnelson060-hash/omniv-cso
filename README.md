# Omniv

**AI Chief Strategy Officer for independent artists, managers and record labels.**

Premium black & gold SaaS — strategy engine, not another content tool.

> Every screen answers: **"What is the highest-impact move this artist, manager, or label should make next?"**

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 (cinematic black `#050505` + gold `#d4af37`)
- Lucide icons · Framer Motion, Recharts, Supabase
- Billing: **Flutterwave** (preserved)
